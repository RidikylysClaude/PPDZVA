# Карточки товаров для ВКонтакте (Маркет сообщества)

Рабочий файл, аналогичный `catalog-listings.md` / `flagma-listings.md` /
`yandex-business-products.md`. Тексты под форму «Добавление товара» в
сообществе `vk.ru/ppdzva` (Товары → Добавить → Вручную).

## Почему заполнено вручную, а не автоматически (2026-09-22)

Автозаполнение текстовых полей (Название/Цена/Категория/Описание) через
браузерную автоматизацию работает нормально, но **загрузка фото — нет**:
ни одно файловое поле VK (ни «Фото» в форме «Добавление товара», ни
поле «Загрузить файл» в массовом импорте YML/CSV) не принимает файлы,
отправленные программно — `input.files` остаётся пустым, хотя
инструмент загрузки отчитывается об успехе. Проверено многими
способами (разные файлы, пути без пробелов, пересоздание диалога с
нуля, прямая инъекция File через JS в обход штатного загрузчика) —
везде одинаково. Похоже на баг конкретно файловых полей VK в этой
сессии автоматизации, отдельный от уже известного бага Claude in
Chrome на avito.ru.

**Дополнительно проверено (важно): форма «Добавление товара» без фото
не сохраняет товар вообще** — при попытке отправить заполненную форму
без картинки VK показывает ошибку «Необходимо главное изображение
товара» и блокирует сохранение. То есть создать карточку «только с
текстом, фото добавить потом» через штатную форму нельзя — фото
обязательно на этапе создания.

**Вывод и рекомендация:** копировать текст по одной карточке — медленно
и всё равно требует фото сразу. Быстрее — **массовый импорт**, см. ниже.

## ⭐ Быстрый путь — массовый импорт всех 5 сразу (`vk_market_feed.yml`)

В том же диалоге «Добавить» → «Из файла» у VK есть импорт по YML/CSV/Excel,
где картинки задаются по **прямой ссылке**, а не файлом — это обходит
баг с загрузкой. Уже подготовлен `vk_market_feed.yml` (в корне этого
репозитория) — YML-фид (стандарт Yandex Market Language, VK его тоже
принимает) со всеми 5 товарами, ссылками на реально работающие фото
`https://ppdzva.ru/img/products/<товар>/...` (все проверены `curl`,
отдают 200) и полными описаниями.

**Как загрузить (вручную, 2 минуты):**
1. `vk.ru/ppdzva` → «Товары» → «Добавить» → «Из файла».
2. Если появится баннер «включить в настройках разделов "Файлы"» —
   нажать «Включить» (уже включено на 2026-09-22, но на случай, если
   выключится).
3. «Загрузить файл» → выбрать `vk_market_feed.yml` из этого репозитория.
4. VK, скорее всего, попросит сопоставить категорию фида
   («Промышленное оборудование») со своей категорией — выбрать вручную
   близкий пункт (при заполнении вручную ближе всего подошла
   «Промышленное оборудование и материалы · Ремонт и строительство» —
   в списке VK нет отдельной категории под электротехнику/РЗА).
5. «Добавить товары» — должны появиться все 5 карточек сразу, с фото.
6. Проверить, что описания и цены отобразились корректно (мог не
   протестировать сам импорт до конца — см. блокер ниже).

**⚠️ Не протестировано до конца** — сам файл через автоматизацию
загрузить не удалось (тот же баг с файловыми полями), поэтому финальный
результат импорта (сработает ли схема YML именно так, как принимает
VK) не подтверждён на практике. Если что-то пойдёт не так — сообщить,
поправлю файл.

## Как добавлять по одной карточке (запасной вариант, если импорт не сработает)

1. `vk.ru/ppdzva` → блок «Товары» → «Добавить» → «Вручную».
2. Прикрепить фото (пути указаны под каждым товаром, до 5 шт.) —
   **обязательно уже на этом шаге**, без фото форма не сохранится.
3. Скопировать «Название», «Цена», выбрать «Категория» из выпадающего
   списка VK — это поиск по частичному совпадению, не список для
   пролистывания. Свободного текста, как в Яндекс.Бизнесе, тут нет.
   Проверенный рабочий вариант — искать «промышленн» → выбрать
   «Промышленное оборудование и материалы · Ремонт и строительство»
   (в списке VK нет отдельной категории под электротехнику/РЗА/реле).
4. Вставить «Описание» целиком.
5. «Добавить товар».
6. Отметить в этом файле `[x]`.

Модуль устанавливается взамен штатного патрона лампы: те же посадочные отверстия и крепёжное отверстие М4 на задней стенке табло, без модернизации корпуса. — пусковой ток (клемма XS1): не менее 220 мА;
— установившийся ток (через ~1 сек): 2–5 мА, потребляемая мощность до 1 Вт;
