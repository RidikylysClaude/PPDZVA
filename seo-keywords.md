# Список ключевых запросов (черновик, база для Wordstat)

Черновик под п.3в ТЗ (`../claude_development_t_z.md`, раздел 3а). У меня нет
доступа к живому Wordstat (нужна залогиненная Яндекс-сессия) — структура и
формулировки собраны из уже существующего текста карточек товара и
`analogs.html`; частотности проставляешь сам на wordstat.yandex.ru и
вписываешь в колонку «Частота».

## Как пользоваться

1. Зайти на wordstat.yandex.ru → вкладка «Слова» (не «История запросов»).
2. Вбить запрос **в кавычках** (`"аналог BU/TEL-220-05A"`) — так Wordstat
   считает точную фразу, без «размазывания» по словоформам. Без кавычек —
   для общего ориентира по объёму, с кавычками — для реальной оценки.
3. Правая колонка Wordstat («Также искали») — источник смежных формулировок,
   которых нет в этом черновике. Стоит пробежаться по ней для каждой модели
   и дописать найденное в таблицу.
4. Частоты < 10/мес — не значит «не делать», для B2B ниши с узкой аудиторией
   это нормально; ориентируйся на относительное сравнение формулировок между
   собой, не на абсолютные цифры.
5. После сбора частот — самые весомые формулировки сверить с текстом карточки
   товара (блок «Что заменяет / Аналог») и meta description: если фразы из
   Wordstat дословно не встречаются в тексте — дописать.

### ⏳ ОТКРЫТАЯ ЗАДАЧА — маркировки ламп накаливания (идея пользователя, 2026-08-23)

**Идея (от пользователя):** ЭИС-ЛН-220-К(Б) разработан именно потому, что
конкретные лампы накаливания для табло ТСБ больше не производят, а прямая
замена на светодиод без имитации броска тока не работает со штатной
защитной аппаратурой (см. описание на `eis-ln-220-kb.html`). Люди по
инерции продолжают искать эти несуществующие лампы по номенклатуре —
если указать точные маркировки ламп в SEO, покупатель, ищущий
несуществующую лампу, попадёт на наш ретрофит.

Стратегически то же самое, что уже отработано на БУВВ/БПВВ/РС-80 (спрос
на нечто недоступное → страница-замена), но здесь это не аналог другого
устройства, а замена расходника (лампы) внутри уже существующего табло.

**Статус: ждём от пользователя.**
1. Точные маркировки/артикулы ламп (тип цоколя/патрона, вольтаж — как
   значится в старой проектной документации или как их называют
   снабженцы). Я не подставляю их сам — узкоспециальная электротехническая
   номенклатура, гадать на странице про электрооборудование нельзя.
2. Частоты по этим маркировкам в Wordstat (тот же процесс, что и раньше).

**Как только маркировки будут:**
- Проверить частоты в Wordstat (по аналогии с остальными товарами).
- Добавить в текст `eis-ln-220-kb.html` **честной формулировкой** — не
  «купить лампу X» (читается как будто мы продаём саму лампу), а «лампа X
  снята с производства → ЭИС-ЛН-220-К(Б) устанавливается вместо неё без
  переделки схемы» — тот же паттерн, что уже есть в тексте про
  импульсные реле/приборы контроля цепей.
- Добавить маркировки в JSON-LD (`isSimilarTo`, по аналогии с РС-80 —
  массив записей, если ламп несколько).
